# 调音器琴头对齐与界面精简

按用户提供的参考图，同时更新 [Figma 已采纳调音器](https://www.figma.com/design/smeuuUaTOYE1URHhIGbzyd?node-id=2745-255) 与 iOS 界面。

后续琴头已放大至 290pt，当前尺寸和适配规则见 [琴头放大同步](2026-10-31-tuner-headstock-scale-sync.md)。下文保留首次对齐时的尺寸记录。

## 结果

- 六个选弦按钮改为圆形，仅展示音名；VoiceOver 仍读出弦号和音名，选中态仍为品牌橙色。
- 按实际琴头素材中的弦柱中心定位，左右依次为 D₃ / A₂ / E₂ 与 G₃ / B₃ / E₄。改换调弦预设后，按钮上的实际音名随目标更新。
- 移除琴头下方的收音提示条、分隔线、A4 校准与标准音底栏。右上角设置保留校准；权限设置和继续调音仅在需要时出现于上方反馈区。
- 沿用现有琴头素材、顶部图标、字体与颜色令牌。Figma 复用原六个组件实例，未替换为整屏图片，原工具入口的目标画板 ID 保持有效。

## 对齐依据

原始透明琴头图为 971 × 1619。三组弦柱中心的素材纵坐标为 368 / 663 / 951。旧版按 90pt 等间隔布局，越向下越偏离素材中的弦柱。

Figma 新图像尺寸为 258 × 430.177pt，保持原图比例，不再使用带留白的 228 × 386 槽位。六个按钮直径 48pt；相对图像的纵向中心为 97.780 / 176.163 / 252.686pt，同一行左右同高。

iOS 将图像和按钮放在同一坐标系中，按同一缩放比例转换这些素材坐标。窄屏会等比缩小琴头；超大字号只在内容宽度达到 360pt 时使用 64pt 按钮，其他情况保持 48pt，避免上下按钮重叠。

## 验证

- 新圆形 / 无底栏回归先在旧界面失败，旧按钮为 60 × 68pt。
- 界面测试读取实际屏幕坐标，检查六个按钮中心与图像锚点的误差不超过 1pt，同时验证手动 / 自动选弦、校准设置、权限状态和无信号状态。
- 独立 Swift 审查发现 375pt 窄屏超大字号的重叠，已在 iPhone SE 3 上先复现失败，再收紧大圆按钮的宽度条件，并增加同侧按钮不相交断言。
- 结果与截图见 [结构化验收记录](../qa/2026-10-31-tuner-headstock-alignment-results.json)。此次只修改界面，音频分析逻辑沿用上一轮已验收的实现。
