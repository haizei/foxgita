## 目标与已经采纳的设计

在现有“跟谱练习”中新增“原谱跟弹”，允许用户导入图片/PDF、标记谱行后直接按节奏跟线弹奏。入口采用本次入口探索的**方案 3（分段切换）**；跟弹页采用更早选定的**方案 1（整页游标）**，两者不是同一组方案编号。

已采纳且不重复询问：

- 创建练习保留“自由练习 / 跟谱练习”。跟谱练习下增加“跟弹方式：曲谱跟练 / 原谱跟弹”。
- 曲谱跟练保留已有曲谱库路径；原谱跟弹的主操作为“上传谱子”。
- 原谱路径不以自动识谱与音符校正为开练前提。
- 上传 → 标记谱行 → 原谱整页跟线。保留原谱中的记谱、和弦与可见标注。
- “3 秒准备”位于训练范围按钮右侧，显示 3 → 2 → 1，支持取消。
- 设计中的 72 BPM、4/4、2–3 行及页数是示例，不自动成为正式默认值。

### 补充：BPM 与节拍器继承事实

- 普通 `MetronomeEngine` 的每主拍时长为 `60 / BPM`，拍号分母标识主拍单位。因此 6/8、80 BPM 表示每分钟 80 个八分音符拍，每小节 4.5 秒；不自动解释为附点四分音符。
- `ScoreTempo` 独立保存 `beatUnit`，默认四分音符；6/8、80 BPM 且 `beatUnit=4` 时每小节 2.25 秒，只有 `beatUnit=8` 才是 4.5 秒。不得只复制 BPM 数字。
- 普通练习保存拍号、逐拍强弱、细分、音色、音量及强拍增强；当前 FollowScore 音频引擎没有读取这些设置。Q3 是本轮要求新增的继承桥接，并非已经实现。
- 当前跨练习恢复查询只恢复 BPM，其余配置来自当前练习项；不能据此声称所有声音设置都会跨练习自动继承。

证据：`MetronomeEngine.swift:666`、`MetronomeMeter.swift:105`、`ScoreDocument.swift:16`、`ScoreTimeline.swift:18`、`ScoreSynthesisPlan.swift:25`、`PracticeDetailView.swift:441`、`PracticeResumeQuery.swift:125`。拍单位已由 Q8 确认，半拍与强弱拍相位已由 Q12 确认；以开发规格第 5 节为准。
