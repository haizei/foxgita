# 首页日期选择与历史练习恢复

状态：三项推荐均已由用户确认，已实现并通过模拟器验收（2026-10-30）。

## 用户要求

保留新版紧凑首页，在顶部周历恢复日期点选、左右滑动查看历史周及对应练习。

## 已核实的现状

- 首页仍保留练习浏览日、浏览周及按日期过滤的历史查询。
- 新版 ProgramHero 的七日状态仅为展示，没有接入日期选择；旧日期组件仅在非今天时出现，导致今天没有进入历史的入口。
- 旧日历以周一为一周起点，支持之前 26 周到本周，共 27 周，不包含未来周。
- 旧换周规则：历史周自动选周一，回本周选今天；选择已在目标周时保留。
- 原始历史列表排除方案分段；新版顶部有效练习标记包含方案分段，存在打卡和列表口径不一致。

## 沿用的现有边界

- 点击日期查看对应归属日的练习，不改变练习原始日期。
- 历史列表无创建、推荐、行滑动编辑和删除入口。历史详情禁止继续旧日计时和新增录音；保留现有内容编辑与显式保存规则。
- 查看空日期显示空态，不填入示例练习。
- 当前周的未来日期沿用“尚未到来 / 先练今天”的状态，不创建未来练习。
- 从历史详情普通返回或切换 Tab 保留选择；显式回到今日的路由切回今天。
- 跨日只让原本查看“今天”的状态跟随新今天，不抢走历史浏览选择。
- 初始布局与程序定位不能意外更改练习浏览日。

## 已确认的交互决策

| 决策 | 用户选择 |
| --- | --- |
| 日历与外层轮播手势 | 日期区域左右翻周，卡片标题区域切换方案卡 |
| 翻周与练习浏览日 | 沿用旧规则：历史周选周一，回本周选今天 |
| 历史列表来源 | 显示当日全部有效练习，包含方案分段并标注来源 |

补充实现边界：历史状态继续保留新版卡片；历史周显示日期范围，提供回到今天入口。当天清单继续排除独立方案分段，历史页展示同一份实际练习事实，统计不重复累加。

## 验收范围

- 新卡片中的七个日期可点击，选中日与今天、已练习三种状态能区分。
- 周历左右滑动确实展示历史周，外层方案轮播不抢同一手势。
- 日期、周标题与下方列表一致，初始显示不跳至最早周。
- 历史日期空态、详情禁止旧日计时/录音、返回保留选择及回到今天。
- 跨月、跨年、周一边界与后台跨日。
- 按最终决定校验方案分段与打卡点口径。

已完成日期 / 统计 / 详情回归、历史来源集成、点选与返回状态，以及两端翻周边界和横竖手势测试。日期运算边界沿用现有 StatsAggregator 单测；未额外执行真机跨日驻留。具体结果见 [验收记录](../qa/2026-10-30-practice-history-restoration.md)。
