# 调音器前端比例同步

设计来源：[Figma TL-02](https://www.figma.com/design/smeuuUaTOYE1URHhIGbzyd?node-id=2745-255)，以及共用布局的 Drop D、DADGAD 画板。用户已确认去除音名数字、两行说明，并优化琴头与字母比例。

## 实现

- 中央音名基础字号 80，两侧音名 30，常规选弦按钮直径 52；保留 Dynamic Type 和大字号滚动布局。
- 琴头素材最大宽 300，保留 971:1619 比例。按钮中心仍对齐原图的 368/663/951 三行弦柱；素材透明边缘与按钮区共享空间，按 300/282 比例适配窄屏。大字号按钮保持 64，并让出对应图片宽度。
- 屏幕只显示 E、A、D 等音名，整体降半音继续显示完整 E♭ 等变音记号。弦号、八度和目标频率保留在 VoiceOver 值中，不影响预设、A4 校准或检测计算。
- 移除目标频率说明行和正常实时方向/调准文字行，保留音分、指针和调准颜色；VoiceOver 继续提供状态。弱音、重新拨弦、权限、收音恢复、标准音及既有大幅偏离提醒仍可见。
- 沿用现有 SwiftUI 页面和主题，不使用整页设计截图作为素材。Figma 提供的琴头、返回、设置、下拉四项资源已逐项下载到临时目录核对，SHA-256 均与项目本地素材一致，继续直接复用。

## 验证

更新既有界面断言：旧版按钮宽 48 对新设计 52 的断言失败，证明能够捕获此次比例变化。新布局验证字母显示、独立的 VoiceOver 值、三套已有预设及整体降半音、A4 校准、按钮与弦柱对齐、大字号深色、弱音撤数及权限提示。

状态查找使用 `tuner.feedback` 标识和 label 条件，避免 XCTest 将 `tuner.cents` 的 VoiceOver value 误认为可见提示。细节结果及测试包路径记录在 [QA 结果](../qa/2026-11-01-tuner-frontend-figma-sync-results.json)。此次为前端同步，不以模拟器截图声明真机拾音或端到端性能变化。

结果：49 项音高/模型测试、3 项流式测试通过；修正查询歧义后的全部 7 项界面测试通过。另在 iPhone SE 3（375 pt、iOS 26.4）通过琴头对齐、大字号深色和手动/自动/预设切换 3 项界面复验。普通、整体降半音、深色大字号及 SE 截图已保存在对应 QA 目录。规范审查与设计一致性审查均无剩余必须修复项。
