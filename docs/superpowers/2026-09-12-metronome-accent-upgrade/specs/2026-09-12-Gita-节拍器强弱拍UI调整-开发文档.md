## 2026-09-20 · Beat Bars 直接编辑补充（覆盖旧循环与多拍布局）

- Display Card 的整根 Beat Bar 作为独立点击目标，点击只修改对应拍；未填充区域同样可点，每拍触控宽高均不小于 `44pt`。
- Meter Sheet 与 Beat Bars 统一按“强 → 次强 → 普通 → 静音 → 强”循环；本规则覆盖下文 2026-09-13 补充中的递增循环描述，不改变四态持久化编码。
- 停止时修改立即生效；播放中柱高立即显示 Configured Rhythm Configuration，声音仍在下一 Bar Boundary 原子切换，当前小节不中途混用两套 Accent Pattern。
- 变速训练运行时 Beat Bars 不修改状态，点击提示“变速训练中暂不可调整重音”；历史练习允许编辑，但继续使用显式保存修改。
- VoiceOver 朗读“第 N 拍、当前状态、下一状态”；锁定时朗读“已锁定”。
- `2...6` 拍保持卡内等宽布局；`7...12` 拍改为水平滚动，以保证每拍最小触控尺寸。

## 2026-09-13 · 拍内自然强弱层级补充

细分节奏不再把一拍内所有发声音符视为同等弱拍，而是使用“主拍／次拍／弱细分／休止”四类时间角色：

| 节奏型 | 拍内角色顺序 |
|---|---|
| 四分音符 | 主拍 |
| 两个八分音符 | 主拍 → 弱细分 |
| 八分休止加八分 | 休止 → 弱细分 |
| 三连音 | 主拍 → 弱细分 → 弱细分 |
| 三连音前休 | 休止 → 弱细分 → 弱细分 |
| 三连音后休 | 主拍 → 弱细分 → 休止 |
| 两八分加休止 | 主拍 → 弱细分 → 休止 |
| 四个十六分 | 主拍 → 弱细分 → 次拍 → 弱细分 |

- 主拍沿用所属 Beat Bar 的强／次强／普通音色；所属 Beat Bar 为静音时，整拍内不发声。
- 次拍与弱细分分别使用普通主拍约 `85%`、`65%` 的增益；次拍同时使用介于重音与普通拍之间的音色。
- 休止作为真实时间位置参与音频时钟推进，但不发声，不发布视觉事件，也不触发振动。前置休止不再把第一个实际发声音符误判为主拍。
- Beat Bars 只在真正的主拍事件短时换色约 `120ms`；一拍内细分不会触发竖柱闪烁。
- Beat Track 的“所有节拍／重音节拍／单摆”仍只响应主拍；“重音及次节拍”中，主拍整条点亮，次拍使用 `72pt` 中央反馈，弱细分使用 `40pt` 且更浅的中央反馈。
- 触觉只保留在强主拍，次拍、弱细分和休止均不触发。

对应自动化覆盖八种节奏型角色、递减增益、十六分 `主－弱－次－弱` 事件顺序、前置休止时间线及四种 Beat Track Mode 映射；3 个测试套件共 33 项，全部通过。

## 2026-09-13 · Beat Track 四态交互与递增重音补充

- Beat Track 从静态装饰区升级为可点击反馈按钮，点击顺序为“所有节拍 → 重音节拍 → 单摆 → 重音及次节拍 → 所有节拍”，默认所有节拍，选择仅在当前练习期间保留。
- 所有节拍：每个主拍整条点亮约 `180ms`；静音拍使用灰色反馈。重音节拍：仅次强与强拍整条点亮。
- 单摆：每个主拍在左右端点间移动一次，颜色跟随拍级；切分次拍不改变方向，停止回到左端。系统开启“减少动态效果”时改为端点瞬时切换。
- 重音及次节拍：非静音主拍整条点亮，所属切分次拍显示较窄、较浅的中央脉冲；静音拍及其切分均不点亮。
- 切换模式时轻触觉反馈并显示模式名称 1 秒；VoiceOver 朗读当前模式和下一模式，浮层名称不重复朗读。
- Meter Sheet 的“重音”标题水平居中；单拍点击循环改为“静音 → 普通 → 次强 → 强 → 静音”，不改变既有持久化编码。
- 音频引擎以实际排程帧发布主拍与次拍视觉事件，Display Card 根据 Beat Track Mode 映射表现，避免 UI 自建计时造成音画漂移。

对应自动化覆盖：Beat Track 模式循环、四种脉冲策略、递增重音顺序及 Display Card 四次点击 UI 流程。

### Beat Bars 播放边框规则

- 柱体播放高亮仅改变内部填充：落拍时统一替换为高对比深暖棕 `#732E0D`，让强、次强、普通及静音状态都能产生明确的到拍体感。
- 所有拍级与声音模式下，柱体边框始终保持中性浅灰色，不参与闪烁。
- 打鼓模式的强拍白色内部闪光、柱内拍点高亮及 Beat Track 反馈保持不变。

## 1. 需求背景与问题定义

在 Gita 练琴主流程中，节拍器的视觉反馈与操作流畅度是练习详情页的核心体验。此前节拍器重音存在以下体验与实现断层：

1. **层级过深与割裂：** 设置面板点击重音会弹出独立的二级弹窗（`MetronomeAccentSheet`），破坏了 Figma C 动线“单一设置面板直观调节”的设计初衷。
2. **四拍柱物理感与强弱区分缺失：** 主卡片落拍柱此前为简化的连续高度矩形，未能还原 Figma `1009:183` 中带有物理槽位、细分割线与离散等分高度的精致视觉设计。
3. **音符图标精细度不足：** 此前采用 SF Symbols 动态拼接，缺少 Figma 原生设计的高保真拟物微渐变音符质感。
4. **多拍场景布局无弹性规范：** 在 3/4 拍、4/4 拍、6/8 拍等不同拍号下，主卡片与设置面板缺乏统一的撑满与滚动约束。

## 2. 核心决策树与对齐结论（Q1~Q5 全量 A 选项）

在进入代码实施前，通过与 Figma 深度对齐并经用户决策，确立了以下 5 项基石原则：

| 决策点 | 核心方向 | 具体实施规格 |
|---|---|---|
| **Q1 · 设置页形态** | 放弃二级弹层，内联重音胶囊条 | 移除 `MetronomeAccentSheet`，回归 Figma `841:217`。在 `MetronomeSettingsSheet` 中「重音」项下方直接嵌入内联 `Accent Sequence`（362×60pt 浅灰胶囊 `#F5F6F8`），点击直接原地切换。 |
| **Q2 · 强弱四态循环** | 标准 4 态顺时针循环阶梯 | 点击音符原地按以下固定阶梯循环：<br>`强 (.strong, 3/3)` $\rightarrow$ `次强 (.medium, 2/3)` $\rightarrow$ `普通 (.weak, 1/3)` $\rightarrow$ `静音 (.mute, 0/3)` $\rightarrow$ `强`。 |
| **Q3 · 四拍柱物理格** | 离散物理三等分积木槽 | 还原 Figma `1009:183`。四拍柱高 48pt，圆角 8pt，底色 `#EEF0F3`。内部由 2 条 1pt 分割线（`#D0D3D9`）离散分为 3 格：<br>• 强拍：填满 3 格（`#FF7925`）<br>• 次强：填中、下 2 格（`#F4A261`）<br>• 普通：填底端 1 格（`#F9C89E`）<br>• 静音：0 格（保留底色）<br>• 激活时（落拍）：柱内填充替换为高对比深暖棕 `#732E0D`，边框不变。 |
| **Q4 · 音符切图资源** | 原生高精切图资产管线 | 将设计切图提取并导入 `foxgita/foxgita/Assets.xcassets`，使用带拟物微渐变质感的切图资产替换系统符号。 |
| **Q5 · 多拍排版自适应** | 居中等宽与边界滚动结合 | • **主卡片四拍柱**：拍数 $\le 4$ 时等宽最大 80pt 撑满居中；$> 4$ 拍等比缩窄，全场景保持不横向滚动。<br>• **设置页内联条**：拍数 $\le 4$ 时等宽撑满；$> 4$ 拍启用水平 `ScrollView`，每格触控区域维持 $\ge 44\text{pt}$。 |

## 4. 架构设计与核心代码实现

### 4.1 数据模型层：`MetronomeMeter.swift`

在 `MetronomeBeatKind` 中扩展离散分段格数与资产映射契约，实现完全类型安全的 4 态循环：

```swift
public enum MetronomeBeatKind: String, Codable, CaseIterable, Sendable {
    case strong
    case medium
    case weak
    case mute

    public var filledBarsCount: Int {
        switch self {
        case .strong: return 3
        case .medium: return 2
        case .weak: return 1
        case .mute: return 0
        }
    }

    public var assetName: String {
        switch self {
        case .strong: return "MetronomeAccentStrong"
        case .medium: return "MetronomeAccentMedium"
        case .weak: return "MetronomeAccentWeak"
        case .mute: return "MetronomeAccentMute"
        }
    }

    public var nextInCycle: MetronomeBeatKind {
        switch self {
        case .strong: return .medium
        case .medium: return .weak
        case .weak: return .mute
        case .mute: return .strong
        }
    }
}
```

### 4.2 节拍器设置面板：`MetronomeSettingsSheet.swift`

在「重音」行直接内联渲染浅灰圆角容器，支持根据拍数动态切换等宽撑满与横向滚动：

```swift
private var accentSection: some View {
    VStack(alignment: .leading, spacing: 10) {
        Text("重音")
            .font(GitaFont.body(15, weight: .semibold))
            .foregroundColor(GitaTheme.textPrimary)

        accentSequenceView
    }
}

@ViewBuilder
private var accentSequenceView: some View {
    let beats = meter.beatsPerBar
    if beats <= 4 {
        HStack(spacing: 8) {
            ForEach(0..<beats, id: \.self) { index in
                accentButton(index: index)
                    .frame(maxWidth: .infinity)
            }
        }
        .padding(.horizontal, 12)
        .frame(height: 60)
        .background(Color(hex: 0xF5F6F8))
        .clipShape(RoundedRectangle(cornerRadius: 12, style: .continuous))
    } else {
        ScrollView(.horizontal, showsIndicators: false) {
            HStack(spacing: 8) {
                ForEach(0..<beats, id: \.self) { index in
                    accentButton(index: index)
                        .frame(width: 52)
                }
            }
            .padding(.horizontal, 12)
        }
        .frame(height: 60)
        .background(Color(hex: 0xF5F6F8))
        .clipShape(RoundedRectangle(cornerRadius: 12, style: .continuous))
    }
}
```

### 4.3 主卡片四拍柱：`MetronomeDisplayCard.swift`

四拍柱由 3 等分离散格构成，采用 `VStack(spacing: 1)` 并注入 `AccentTrackDivider`：

```swift
private func beatBar(index: Int) -> some View {
    let kind = meter.accentAt(index)
    let filledCount = kind.filledBarsCount
    let isCurrentBeat = isPlaying && currentBeat == index

    VStack(spacing: 1) {
        // Top slot (segment 3)
        segmentSlot(isFilled: filledCount >= 3, kind: kind, isActive: isCurrentBeat)
        // Mid slot (segment 2)
        segmentSlot(isFilled: filledCount >= 2, kind: kind, isActive: isCurrentBeat)
        // Bottom slot (segment 1)
        segmentSlot(isFilled: filledCount >= 1, kind: kind, isActive: isCurrentBeat)
    }
    .background(GitaTheme.accentTrackDivider) // 1pt divider lines
    .clipShape(RoundedRectangle(cornerRadius: 8, style: .continuous))
    .background(
        RoundedRectangle(cornerRadius: 8, style: .continuous)
            .fill(Color(hex: 0xEEF0F3))
    )
}
```

## 5. 无障碍辅助功能（Accessibility / WCAG 2.2）

1. **多重感官线索：** 状态表达不单依赖颜色，通过“分段高度 + 高精切图 + 文本说明”三重通道交付。
2. **触控热区保证：** 设置面板内联音符按钮无论在 4 拍等分还是多拍横滑场景下，有效触控热区均 $\ge 44 \times 44\text{pt}$。
3. **VoiceOver 语音契约：**
   - 朗读格式：`"第 X 拍，[强/次强/普通/静音]，可调节"`。
   - 包含明确的操作 Action 提示（`"轻点两次循环切换强弱状态"`）。
