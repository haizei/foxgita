## 1. 文档目的

本文定义在初始化流程已经可用之后，空状态、创建/编辑、Ready 三屏如何按 Figma 验收，以及项目类型、当前阶段如何作为选填写回项目。

不改创建门槛：名称 + 完成目标即可创建。不改 Ready 只从空状态进入。不改 Schema。

## 2. Problem Statement

按 Figma 做的第一轮视觉之后，创建页在键盘弹起时被压扁：完成目标和当前重点重叠，主按钮贴进输入区，占位示例看起来像已填内容，未启用的「创建项目」浅到看不清。

同时，上一轮实现按「表单不出现类型/阶段、保存写成空」落地，和 Figma Goal + Focus 上的芯片、阶段行，以及 Ready 上的「串联整首」徽章不一致。用户无法在创建时留下类型和阶段，列表和 Ready 也画不出稿上的阶段。

## 3. 目标

1. 三屏视觉以 Figma Project Initialization 为准，用现有设计 token，不新增色值。
2. 键盘弹起时，当前字段和主按钮仍然可见，字段不重叠。
3. 占位不是预填；未启用主按钮仍能读出「创建项目」。
4. 类型、阶段选填且写入项目；未选不阻塞创建。
5. 有阶段才在 Ready 和已有阶段展示处画徽章。

## 4. 范围

### 做

- 空状态白卡片（色标、说明、三条收益、主/次操作、脚注）。
- 创建/编辑：名称、目标、类型芯片、当前阶段、当前重点。
- 阶段：所有类型共用五档（熟悉内容 / 分段练习 / 串联整首 / 稳定演奏 / 完成），可不选。
- 类型：歌曲 / 技巧 / 演出准备，单选，可取消。
- Ready：成功反馈、名称、目标；有阶段才画徽章；有重点才画重点块。
- 修正「保存清空类型/阶段」。

### 不做

- 按类型切换阶段模板。
- 阶段自由输入（旧自由文本见第 6 节）。
- Ready 展示类型、在 Ready 上编辑。
- 返回箭头、预填示例曲目。
- 封面、期限、频率、任务清单、改表结构。

## 5. 页面要求

### 5.1 空状态

无未删除项目时展示。主操作「创建第一个项目」进入创建（`fromEmpty: true`）。次操作「暂不创建，继续自由练习」回到记录的练习分段，不创建项目。

### 5.2 创建 / 编辑

| 字段 | 必填 | 说明 |
|---|---|---|
| 项目名称 | 是 | 占位示例不可当已填 |
| 完成目标 | 是 | 浅橙底表示强调框，不表示已填 |
| 类型 | 否 | 歌曲 / 技巧 / 演出准备 |
| 当前阶段 | 否 | 五档 + 不选择 |
| 当前重点 | 否 | 旁注：写下一次练习最值得关注的一件事，不是待办 |

主按钮：创建为「创建项目」，编辑为「保存」。仅关闭，脏了先确认。键盘弹起时字段不得重叠，主按钮不得贴进输入框。

### 5.3 Ready

仅空状态创建成功后进入。顶部「完成」与「先返回项目列表」都回到项目列表。主操作「创建今天的练习项」。没选阶段不画徽章；没填重点不画重点块。

## 6. 数据

沿用 `kindRaw` / `stageRaw`。

- 类型存中文：`歌曲` / `技巧` / `演出准备`，未选为空。
- 阶段存中文：`熟悉内容` / `分段练习` / `串联整首` / `稳定演奏` / `完成`，未选为空。
- 列表、详情、Ready 继续展示字段原文，不必英中映射。

旧项目若存的是不在上表的自由文本：编辑页显示原文，不自动改写；用户另选受控项后再替换。未改就保存则保持原值。

## 7. 验收

- [ ] 空状态是稿上的白卡片，不是灰底短文案。
- [ ] 未填名称或目标时，主按钮不可点且文案可读；占位不是正文色。
- [ ] 只填名称和目标可以创建。
- [ ] 选了类型和/或阶段后，保存能读到对应值；Ready 有阶段才显示徽章。
- [ ] 键盘弹起时，目标与重点不重叠，主按钮在键盘上方。
- [ ] 编辑保存不会把已有类型/阶段清掉。
- [ ] 列表创建、编辑、新建并加入仍不进 Ready。

## 8. 非目标

按类型切换的阶段模板、封面、云同步、跨会话草稿、新埋点。
