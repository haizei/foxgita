# Gita 练习详情改造 PRD：笔记、节拍器与倒计时

**版本**：v1.0 · 2026-10-28

**状态**：产品规则 Q1–Q13 已确认；代码与音色定稿已完成，真机验收待完成。新增量化目标仍为建议值，效果指标尚无实测结果。

**交付范围**：原生 iOS 前端、真实交互、音频与本地领域服务、持久化及兼容。
**配套文档**：[决策访谈](../../design/2026-10-28-practice-ui-rebuild-interview.md) · [工程规格](2026-10-28-practice-ui-rebuild-design.md) · [实施计划](../plans/2026-10-28-practice-ui-rebuild.md)

**已发布规格**：[GitHub Issue #59](https://github.com/haizei/foxgita/issues/59)，标记 `ready-for-agent`。用户已确认以现有练习详情端到端流程为主测试边界；Issue 正文是可独立执行的综合规格，包含八十条用户故事。本 PRD 的效果指标仍是建议值，不因发布自动变成实测结果。

## 1. 问题陈述

日常使用 Gita 跟拍练琴、计时和记录的用户，需要在同一练习中连续完成调节节拍、录音录像、写笔记与回看。当前应用仍使用旧声音面板，缺少新版音效与视觉控件；练习计时依赖节拍器启动，单独录音可能留下零时长记录，暂停、保存及完成的语义也未统一。

用户已反馈音色“太难听”、要求对齐新版界面，并明确指出过 MT-04“这个没变啊”。继续只更新设计或替换局部列表，会让新设计与实际产品脱节，增加操作和记录丢失风险，不能完成本次改造目标。

### 1.1 证据与适用范围

| Figma 审计 | 三个练习、四个节拍器、三个倒计时场景；MT-04 为完整新版面板 | 画板未定义的业务规则由已确认访谈补齐 |

未提供当前任务完成率、留存、音色满意度或支持工单数量基线。本 PRD 不虚构业务收益或用户研究结果。

## 2. 目标用户与核心任务

| 用户场景 | 核心任务 | 本次要解决的阻碍 |
| --- | --- | --- |
| 跟拍、练速度的吉他练习者 | 调整节奏、选择可接受的音色、进行连续或变速训练 | 设置入口缺失，声音与视觉混用，播放中改参不可信 |
| 记录练习过程的吉他练习者 | 正确计时，录音录像，写笔记和添加资料 | 计时依赖发声，暂停联动不一致，笔记保存状态不清楚 |
| 从项目或记录页回看的人 | 修改原笔记、播放附件，继续允许继续的练习 | 编辑来源与完成状态不能混淆，历史累计不能被误改 |
| 使用窄屏、大字号或辅助功能的人 | 找到、理解并操作同一组练习工具 | 长面板裁切、图片控件缺语义、动态反馈妨碍操作 |

这些是本次功能服务的任务场景，不是已完成用户研究验证的人群规模划分。

## 3. 目标与成功定义

以下数值是本 PRD 提出的验收目标；功能规则仍以 Q1–Q13 为已确认依据。

| ID | 目标 | 可验证的成功定义 |
| --- | --- | --- |
| G1 | 用户能在一个练习上下文完成全部核心任务 | 十个设计场景均有真实入口；端到端任务矩阵通过率 100%，没有无操作按钮 |
| G2 | 用户信任实际时长与完成状态 | 含静默、录音、录像、暂停、倒计时的确定性用例时长误差不超过 1 秒；重复到零/保存不重复累计；自动保存和到零误标完成次数为 0 |
| G3 | 用户的记录在返回与失败后仍可恢复 | 笔记、图片、媒体和数据库失败场景全部可重试；验收样本中不可恢复的已保存内容丢失为 0 |
| G4 | 用户可独立控制声音与视觉，并选择合适音色 | 七预设、视觉过滤、静音、振动/闪拍的交叉用例 100% 通过；正式替换素材经需求方试听选定 |

G1–G4 是候选发布验收门槛，G5 是效果假设；没有基线时不承诺提升百分比或收入、留存收益。

## 4. 非目标

1. **新增云后端或跨设备同步**：已确认本轮后端为本地业务服务；云账户、同步和冲突解决需要独立需求。
2. **项目默认配置与步骤覆盖继承**：每条 PracticeItem 保存自己的节拍/声音参数，当前步骤没有稳定实体身份，不隐含扩建模型。
3. **音色市场、上传音色与环境自动识别**：保留七个现有预设名，聚焦现有素材调音；不检测噪声或自动选择声音。
4. **PDF/乐谱解析、新 AI 分析及首页方案重做**：附件本轮只处理图片、可读音频和视频；其他流程有各自需求单。
5. **扩展未定义的细分第二页或改写已发布 schema**：保留八种细分与当前数据库兼容；无必要不新增迁移。

## 6. 需求优先级与验收标准

**优先级口径**：本次是用户明确确认的整组流程改造，不把已承诺功能悄悄移入后续版本。P0 按用户结果聚合；内部可分阶段交付，但功能完成声明必须覆盖全部 P0。

### 6.1 Must-Have / P0

#### R01 · 独立计时与统一运行状态

**预期**：练习实际累计独立于节拍器；静默练习、录音、录像都能产生真实时长。主暂停、返回、完成使用一致的运行规则。

- [ ] Given 节拍器关闭，When 开始练习 120 秒并暂停 60 秒，Then 已练只增加 120 秒，误差不超过 1 秒。
- [ ] Given 录音成功开始且原计时未运行，When 录音 30 秒，Then 实际时长增加 30 秒；权限拒绝不伪造成功或启动录音计时。
- [ ] Given 录音正在采集，When 主暂停，Then 实际计时、已启用倒计时、节拍器及录音均暂停，录音仍是同一片段。
- [ ] Given 用户只暂停录音，When 主暂停后再继续，Then 用户自行暂停的录音仍保持暂停，其他运行按原意图恢复。
- [ ] Given 录音进行中，When 停止录音，Then 附件保存而实际练习继续；停止录音不等于完成练习。
- [ ] Given 有未完成练习，When 返回，Then 内容和实际时长保留且未标完成；上下“完成”入口执行同一动作，保存成功后才完成。

**约束/依赖**：现有 PracticeTimer、PracticeStore、录音服务；时钟推导时长，不靠动画帧或媒体元数据叠加。音频启动失败可提示，但不抹除已发生的练习时长。

#### R02 · 倒计时计划、运行与到零

**预期**：设置与启动分开；倒计时为当前访问临时态，随实际练习暂停和继续，到零不自动完成练习。

- [ ] Given CD-01，When 选择 1–60 分钟或 5/10/15 快捷值并点“完成”，Then 保存暂停计划，不启动练习；点“开始倒计时”才启动。
- [ ] Given 运行或暂停状态，When 重设时长，Then 从新总时长等待启动；倒计时复位不清零已练时长或笔记。
- [ ] Given 节拍器未启用，When 启动倒计时，Then 剩余时间与实际练习仍正常运行。
- [ ] Given 倒计时首次到零，When 音频截止和时钟同时回调，Then 只执行一次停止/录音保存，实际时长截至零点，不自动标完成。
- [ ] Given 用户主动离开练习，When 再进入，Then 不恢复上次临时倒计时；展示设置或相机等子界面不视为离开。
- [ ] Given 提醒权限不可用，When 用户启用提醒，Then 明确显示未启用，倒计时仍可开始；沿用既有倒计时与变速训练互斥规则。

**约束/依赖**：现有 Countdown、音频时间线截止及提醒服务；前台/后台恢复均去重，无声练习不依赖无声播放器保活。

#### R03 · 完整音效与音色设置

**预期**：练习主卡齿轮打开完整白底 MT-04，提供音效、七音色及视觉设置；所有可见操作有真实功能。

- [ ] Given 练习主卡，When 点右上齿轮，Then 打开完整新版 MT-04，包含顶部录音/展开、编号±、耳机、音量/静音、更多、七音色及视觉区。
- [ ] Given 任一音色卡片或编号，When 选择/步进，Then 二者共享唯一选中值，编号 1–7 两端禁用越界；顺序沿现有预设 allCases。
- [ ] Given 未正式播放，When 选择音色或点耳机，Then 按当前配置试听两小节；不启动实际计时、倒计时、训练历史或正式小节计数，重复试听不叠加。
- [ ] Given 正式播放中，When 切换音色，Then 下一次发声采用新音色，BPM、相位和小节连续，无第二路试听、漏拍或叠音。
- [ ] Given 音量 70%，When 临时静音后取消，Then 恢复 70%，计时与拍点持续，保存配置不变成音量 0。
- [ ] Given 面板顶部按钮，When 点录音/展开，Then 分别复用本次练习录音或进入共享状态的大屏节拍器；关闭/下滑/返回不创建第二引擎。
- [ ] Given “更多声音设置”，When 修改强拍增强、振动或闪拍，Then 三者独立，换音色不得暗中启用；螺丝为装饰，不承担关闭操作。

**约束/依赖**：Figma 主件 2646:1275、实例 2651:1380；现有七个稳定 rawValue 和预加载音频引擎。70% 是本验收场景输入，不是修改产品默认音量。

#### R04 · 拍号、速度、细分与训练

**预期**：保留现有完整调速、TAP 与变速能力，并实现新分母控制与明确 BPM 单位。

- [ ] Given MT-03，When 调分子/分母，Then 分子保持现有 2–12，分母仅 2/4/8/16，到边界停止，BPM 单位展示对应分母音符。
- [ ] Given 6/8、120 BPM，When 运行，Then 每秒两个八分音符主拍，不自动按附点四分音符换算。
- [ ] Given 正在播放，When 改拍号、细分或重音，Then 按已有下一小节边界原子应用，待应用与已应用状态可区分。
- [ ] Given MT-01，When 调速或 TAP，Then 保留整体 40–200 BPM 与现有边界生效约定；刻度滑杆保持设计的 40–160 可见范围。
- [ ] Given MT-02，When 设置起始/目标、每阶段小节、步长、预备小节并训练，Then 按配置推进，保留暂停/中断历史和目标保持，不将预备算为正式小节。
- [ ] Given 四态重音和八细分，When 逐项操作，Then 声音与视觉使用同一真实时间线；不出现未定义第二页内容。

**约束/依赖**：现有 Meter、Subdivision、TempoController、训练持久化。旧非标准正整数分母读取显示规范化为 4，下一次用户保存再写回，不批量改库。

#### R05 · 独立视觉偏好与正式小节计数

**预期**：视觉偏好全局保存，可组合；高亮筛选不改变声音。

- [ ] Given 视觉设置，When 同时勾选节拍模块与钟摆，Then 两种反馈共存；全部关闭也允许，不停止真实音频与计时。
- [ ] Given 强/次强/普通三级筛选，When 取消某级，Then 只移除该级运行高亮，保留静态重音图案，发声、力度、节奏位置不变。
- [ ] Given 小节计数开启，When 正式播放，Then 主卡显示“第 N 小节”，第一小节为 1；预备不计，暂停继续保留，重置/新一轮从 1 开始。
- [ ] Given 同一播放过程，When 进出大屏，Then 小节计数与节拍位置一致；不可由已练分钟推算小节。
- [ ] Given 练习 A 改视觉偏好，When 切换练习 B 或重启应用，Then 偏好保持；B 的节拍和声音配置仍是自己的。
- [ ] Given 偏好未保存过，Then 节拍模块开、钟摆关、三级高亮开、小节计数关；振动沿现有默认开，闪拍关。坏值恢复默认，不损坏练习。

**约束/依赖**：全局偏好持久化、实际引擎事件；旧互斥 BeatTrackMode 不再作为用户可选入口，预设不驱动辅助开关。

#### R06 · 笔记、真实录音波形与附件

**预期**：每条练习一份文本笔记，短延迟保存；媒体归属本次练习，录音反馈来自真实输入。

- [ ] Given 连续输入笔记，When 最后一次修改后 600ms，Then 提交最新文本；退后台、返回或完成立即 flush 最新版本，旧保存回调不能覆盖新草稿。
- [ ] Given 保存中/成功/失败，Then 分别显示真实状态，失败保留草稿并允许重试；“已保存”不代表练习完成。
- [ ] Given 四个工具入口，When 使用语音输入/录音/录像/附件，Then 执行各自任务；语音输入为设备端转文字插入光标，暂停练习并保存正在进行的录音，原语音不作为附件保留。
- [ ] Given 录音采集中，When 输入音量变化，Then 波形反映真实麦克风电平；暂停冻结，停止清除活动波形，不以固定图案冒充实时输入。
- [ ] Given 可用系统相机，When 打开录像，Then 实际计时开始/继续，节拍器暂停，已有音频片段先保存；返回相机后手动恢复声音，视频元数据不再次增加实际时长。
- [ ] Given 相机仍可见且倒计时到零，Then 实际累计截至零点，视频可正常保存，不丢弃文件；视频文件时长可长于本次有效练习时长。取消相机不生成空附件或回滚已练时长。
- [ ] Given 相册/拍照/文件选择，When 添加可读图片、音频或视频，Then 保存到应用私有文件并关联本条练习，图片合计最多三张；音视频可在记录中播放。
- [ ] Given 取消、权限拒绝、损坏/不支持文件、重复提交或写入失败，Then 原记录不变、错误可理解且可重试，仅清理本次新增失败文件，不产生假附件或丢失 pending 媒体。

**约束/依赖**：现有录音、系统相机、NoteImageStore、RecordingStore、PracticeStore；支持范围由系统可解码 UTType 判断，不顺带加入 PDF/乐谱解析。

#### R07 · 本地保存、历史兼容与单一事实来源

**预期**：局部设置、未完成内容和媒体可可靠保存，历史、项目投影与统计不产生副本或重复累计。

- [ ] Given A/B 两条练习，When 分别保存 BPM、拍号、细分、重音、音色、音量与强拍增强，Then 各自恢复，不因同一项目串用配置，不继承步骤设置。
- [ ] Given 原练习笔记被修改或清空，When 返回项目笔记列表，Then 从原记录投影反映变化，不额外维护可写副本。
- [ ] Given 通过历史入口查看，When 修改允许编辑的文本/内容，Then 不绕过原入口对累计时长、采集和完成的限制；允许继续的入口沿原权限工作。
- [ ] Given 倒计时与练习时长并存，When 保存/汇总，Then 只保存实际明细作为练习时长，不重复加总倒计时、视频时长或方案汇总。
- [ ] Given V19 与已有旧库升级路径，When 打开新版本，Then 记录、七音色兼容映射和文件关系保持可用；无需新增字段时不改变 schema。
- [ ] Given 任一数据库提交失败，When 返回或完成，Then 保留草稿和 pending 媒体、不提前显示完成；待成功提交后才释放文件所有权。

**约束/依赖**：PracticeItem / PracticeStore 单一写入、既有迁移与 ADR-0010/0011/0012。保护本工作区已有未提交修改。

#### R08 · 音色调音与试听验收

**预期**：改善现有声音的主观可接受度，同时保持跟拍辨认与播放稳定；不以“属性变了”替代真实听感和时间线验证。

- [ ] 先提供同节奏、同系统音量的木质、干净电子及强拍 A/B 对照，记录需求方选择后再更新正式素材。
- [ ] 七预设名称与 rawValue 保持，普通/强拍共 14 份素材完整且许可可追溯；采样格式、峰值余量与现有约 70ms 契约通过资产检查。
- [ ] 80/160 BPM 及密集细分下主拍、细分和强拍无可闻爆音、重叠或削波；强拍增强关闭不被内部配方自动重新打开。
- [ ] 音量 0–100% 不因切换预设变化；校准遵守用户增益控制，无额外隐藏增益或强制路由。
- [ ] 真机确认声音实际切换时刻、无漏拍及两小时连续播放基线；自动化和波形指标不能替代需求方试听。

**约束/依赖**：复用已有预加载/样本时钟；最终素材选择是开发中的内容评审，不阻塞其他模块开发，但阻塞正式素材定稿。

#### R09 · 视觉适配、可访问性与中断恢复

**预期**：十个场景可在真实设备完整操作；前后台和路由变化符合既有连续性规则。

- [ ] 对照设计完成三练习、四节拍器、三倒计时场景，长内容可滚动，安全区/键盘不遮住主要操作。
- [ ] MT-04 保持白底与 Gita 颜色、系统字体层级；默认外观逐场景对照。深色系统外观下该白底面板文字仍清楚，不改写全应用主题。
- [ ] 圆形底座、开关可使用生成图片，但数字、按钮、滑块、复选与状态具有原生可访问语义；所有操作命中区至少 44pt。
- [ ] iPhone 17、SE 3 窄屏及辅助功能字号下文字不裁切、控件不重叠；VoiceOver 能读操作名称与选中状态，不逐拍抢读；减少动态效果时提供静态拍点提示。
- [ ] 锁屏/后台连续运行按既有规则保持；前台动画停止更新不影响音频，返回显示真实计时状态，无声练习靠时钟补算。
- [ ] 来电、路由丢失或音频服务重置保存当前录音并暂停，等待用户明确恢复；耳机断开不无提示自动外放，会话申请失败不遗留假占用。

**约束/依赖**：现有 AudioSessionCoordinator、播放连续性 ADR、系统权限与物理设备；模拟器通过不能替代真机验证。

## 7. 关键交互与状态边界

| 用户动作 | 实际计时 / 已启用倒计时 | 节拍器 | 音频录音 |
| --- | --- | --- | --- |
| 主开始/继续 | 开始/继续 | 按此前启用意图 | 只恢复由主暂停暂停的录音 |
| 主暂停 | 暂停 | 暂停，保留小节/训练 | 暂停而不结束附件 |

| 停止录音 | 保持运行 | 保持 | 结束保存 |
| 临时静音 | 保持运行 | 时间线继续、无声 | 保持 |

## 9. 成功指标与测量计划

### 9.1 先行指标

| 指标 | 建议成功阈值 / 进取目标 | 方法、分母与评估时间 |

| 核心任务完成率 | ≥90% / 100% | 内部/同意参与的试用者，成功完成任务数 ÷ 有效尝试数；任务为打开设置换音色、无声计时、录音暂停、倒计时结束、笔记返回恢复；首个试用周，记录人数与尝试数 |

### 9.2 滞后指标

| 指标 | 建议目标 | 测量方法与窗口 |
| --- | --- | --- |
| 保存可信度 | 均值 ≥4/5，进取 ≥4.5/5 | 改造版本试用满四周，询问“我能确认练习内容已保存”；报告有效回答数与版本，不从满意度推断数据安全 |
| 音色长期接受度 | ≥80% 评分 ≥4/5，进取 ≥90% | 两至四周后对相同试用样本询问清晰度、刺耳和疲劳；单项分别记录，避免总体分掩盖刺耳问题 |
