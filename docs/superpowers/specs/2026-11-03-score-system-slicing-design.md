# 谱行切分识谱

用户已选择此前提出的按完整谱行切分方案，并要求保持模型参数不变，用已提供的清晰谱页实测。本轮直接执行这一已授权方案。

目标：降低单次识谱内容量；保留原页与谱行坐标、和弦图、简谱、歌词；顺序请求、成功谱行缓存、失败谱行单独重试。模型、系统提示词、思考参数（继续不传）、响应格式与240秒超时保持不变，仅用户文字说明当前输入为原页信息和谱行局部。

方案：本地横向暗像素投影找连续的5/6条等距长线，作为谱行锚点；在相邻锚点之间的留白处确定裁剪边界，向上保留和弦图，向下保留歌词/简谱。首次实现保守支持清晰、基本水平的印刷谱页，检测不足时保持整页；不使用生成式修图。固定等高切图会切断音乐内容，逐小节识别会丢失过多上下文，因此本轮不用。

每个谱行请求附带独立页眉图片，仅供元数据参考；音乐位置以谱行图为准。谱行图的source坐标经裁剪矩形逆映射到原页。分段合并不把谱行冒充新增谱页，保持原小节编号及播放顺序；不自动宣称小节编号或重复关系正确。

本轮优化当前iPhone使用的DEBUG直接供应商通道；正式托管服务协议不把谱行当谱页上传，也不虚构已部署。真实测试使用用户提供的同一文件和原机配置，顺序识别各行、记录每行和总耗时/成功状态/校验问题；遇首个超时停止本轮，避免重复失败调用。输出仅作待核对草稿，成功返回不代表音符识别准确。

风险：切分检测不确定时可能退回整页；模型在不同谱行上可能给出不一致元数据、编号或跨行关系，必须保留核对项，不静默丢音符。清晰原图的结果不外推到最初屏幕翻拍照片。
