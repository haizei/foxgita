# 练习详情、笔记、节拍器与倒计时改造规格

日期：2026-10-28。来源：用户通过 grill-with-docs 分两轮采纳 Q1–Q13，记录见 [访谈](../../design/2026-10-28-practice-ui-rebuild-interview.md)。状态：规则及主测试边界已确认，综合规格已发布为 [Issue #59](https://github.com/haizei/foxgita/issues/59)，标记 `ready-for-agent`；产品代码尚未实施。

产品目标、用户故事、优先级、量化指标及需求单冲突见 [正式 PRD](2026-10-28-practice-ui-rebuild-prd.md)。本文件负责工程行为细节；PRD 中的效果目标为建议值，不是已测结果。

## 目标与边界

将 Figma「练习页面相关 · 笔记 / 节拍器 / 倒计时」的十个场景落为可用的原生应用，覆盖前端、音频、计时、录音录像、附件、本地保存及兼容性。

- 技术基线：SwiftUI、Observation、SwiftData，最低 iOS 18；现有 schema V19。
- 后端指本地领域服务、文件、持久化和兼容逻辑，本轮不新增云服务。
- 保留当前工作区既有功能与未提交修改；不重置仓库，不将其他工作混入提交。
- PracticeItem 是单份笔记、累计时长、配置及媒体关系的事实来源；不增加步骤实体、项目配置继承或第二份练习时长。
- 沿用现有七种音色的稳定 rawValue、八种细分、四态重音、40–200 BPM、2–12 拍及变速训练能力。
- 不实现未定义的第二页细分、PDF/乐谱解析或新的 AI/同步功能。

## 数据归属与兼容

| 数据 | 归属 | 保存边界 |
| --- | --- | --- |
| BPM、拍号、细分、重音、音色、音量、强拍增强 | PracticeItem 现有字段 | 设置修改后与笔记一样可保存，不依赖完成 |
| 节拍模块、钟摆、三级高亮、小节计数显示 | 应用全局偏好 | 修改即保存，重新打开及切换练习保持 |
| 振动、闪拍 | 全局设备反馈偏好 | 独立于声音预设保存 |
| 临时静音、设置面板、全屏状态 | 当前详情访问 | 离开后不以音量 0 写入配置 |
| 倒计时计划、运行状态 | 当前详情访问 | 离开取消；不写入 PracticeItem |
| 文本笔记 | PracticeItem 单份 note | 短延迟自动保存，离开/退后台强制提交 |
| 图片、录音、视频 | PracticeItem 关联本地文件 | 数据保存成功后才移除 pending 文件所有权 |

全局偏好采用有版本字段的单份 UserDefaults 数据；缺失或坏值恢复默认，不影响原练习。默认节拍模块开、钟摆关、三级高亮全开、小节计数关；振动沿用现有默认开，闪拍默认关。旧 BeatTrackMode 是访问临时状态，无持久化迁移来源。

现有字段已足够保存本轮每条练习的数据，不预设新增 SwiftData schema。保留 V19 及旧 schema 字节兼容；若实现中确需新字段，先补迁移设计与旧库测试，不编辑已发布 schema。

## 界面与视觉

主内容按节拍器 → 计时卡 → 步骤 → 笔记与媒体排列。长内容滚动，不把设计画板高度当固定设备高度。

主卡保留拍号、速度、细分三列，右上角齿轮进入音效与视觉设置。拍号/细分进入 MT-03，速度进入 MT-01/02。设置面板明确关闭并支持下滑；装饰螺丝不响应点击。

MT-04 为白底完整面板，包含顶部录音与展开、音效编号 ±、耳机试听、音量与临时静音、更多设置、七音色卡片、节拍/钟摆复选、三级高亮、小节计数。更多设置包含强拍增强、振动、闪拍。展开进入同一节拍器状态的大屏视图，不启动第二个引擎；录音按钮复用当前练习录音命令。

颜色遵循 Gita：主橙 #FF7925、文本 #292929、次级文本 #999999、浅底 #F6F6F6、边框 #D6D9DE。白底仅用于本轮指定面板，不改写全应用颜色变量。字体沿用 Gita 系统字体与 Dynamic Type，按标题/分区/正文/说明/数字层级匹配 Figma；不为预览字体额外引入 Noto 字库。

圆形底座与小节开关图片来自顶层 `design-assets/metronome-sound-visual-v2/`，加入 Assets，保持透明边界。原生选中状态及可访问名称覆盖在图片上。控件命中区至少 44pt；窄屏与大字号允许换行或改变列数，不裁掉文字。降低动态效果时钟摆用静态拍点提示，VoiceOver 不逐拍抢读，停止时回到静态状态。

## 计时、录音、录像的统一行为

PracticeTimer 独立于音频引擎。主开始启动/继续实际时长及已启用倒计时，按用户意图决定是否启动节拍器。支持直接关闭节拍器练习；临时静音只关声音，不停止拍点或时钟。音频启动失败须报告且不丢弃已启动的计时。

| 动作 | 实际计时 / 倒计时 | 节拍器 | 录音 |
| --- | --- | --- | --- |
| 主开始/继续 | 开始/继续；未启用倒计时不自动创建 | 按当前启用意图恢复 | 只恢复由主暂停暂停的录音 |
| 主暂停 | 同时暂停 | 暂停，保留小节计数与训练进度 | 进行中录音暂停，不结束文件 |
| 录音自身暂停 | 继续 | 继续 | 暂停采集 |
| 录音自身继续 | 若练习暂停则先继续计时 | 按既有意图，不强制打开 | 继续原片段 |
| 停止录音 | 继续 | 保持 | 停止、保存附件 |
| 开始录音 | 成功获得权限并开始采集后开始/继续 | 保持，可与录音共存 | 开始新的录音片段 |
| 打开录像 | 可用且展示后开始/继续 | 暂停，退出后不自动续播 | 先保存正在进行的音频片段 |
| 录像保存或取消 | 保持实际计时 | 等用户明确恢复 | 视频保存时形成附件，取消不生成空附件 |
| 开始语音输入 | 暂停 | 暂停 | 结束并保存当前片段 |
| 倒计时到零 | 截至零点，事件只执行一次 | 停止 | 保存并结束 |
| 返回 | 保存并停止，取消临时倒计时 | 停止 | 保存并结束，不标记练习完成 |
| 完成（上下入口） | 同一结束保存命令 | 停止 | 保存并结束，成功后标记完成 |

主暂停与录音自身暂停要区分原因，主继续不得擅自恢复用户自行暂停的录音。展示相机/全屏节拍器/文件选择器不等于离开练习，不能被通用 onDisappear 误停并取消倒计时。

系统相机不提供本轮自定义录制时钟：相机可见时倒计时仍遵守截止时间，实际练习累计截至零点；到零不丢弃正在生成的视频，返回时允许用户保存，视频文件时长不等同于练习累计时长。取消相机不回滚已经发生的练习时长。不要根据视频元数据再次叠加时长。

后台与锁屏仍按现有连续性 ADR；视觉停止更新而音频/计时保持。来电、路由丢失、音频服务重置则保存当前录音、暂停运行并要求手动恢复，禁止自动外放。静默练习不靠循环无声播放器保活，恢复前台按时钟重新计算；后台截止的保存操作在可运行时补做且时间值以截止点为准。

## 倒计时与训练

CD-01 “完成”只保存新的暂停计划，不启动练习；“开始倒计时”才开始。变更时长从新总时长起算；倒计时复位不清零实际时长。到零显示已结束，可重新开始，不自动完成练习。

沿用现有倒计时与变速训练互斥、前后台提醒和音频时间线截止约束。无节拍器运行时也能倒计时；没有音频引擎时不调用音频截止作为唯一完成来源。两种完成来源必须合并为同一个幂等事件。

MT-02 继续沿用现有起始/目标、每阶段小节、步长、预备小节与目标保持逻辑及历史。UI 不缩减已存在的范围。主暂停、系统打断及返回都通过统一入口保留正确训练结果。

## 拍号、视觉与小节

分母按 2、4、8、16 步进，到边界停止。BPM 单位是当前分母音符；6/8 的 120 BPM 每秒两个八分音符。细分的时值仍相对一个所选主拍表达，不通过分母额外缩放两次。旧的非标准正整数分母显示时规范化为 4，直到下一次用户保存才写回；不静默批量改旧记录。

拍号、细分、重音继续于下一小节边界一起应用；速度按现有 TAP/训练边界约定处理，UI 能区分待应用与已应用值。

节拍模块与钟摆可同时启用，也可同时关闭。强/次强/普通高亮过滤只影响运行高亮，保留静态重音图案，不改变声音、训练和计数。强拍增强只影响音频；振动和闪拍独立，不再由拍手预设自动打开。

主卡右上方展示“第 N 小节”；正式首小节为 1，预备不计；暂停继续保留，显式重置/新的播放轮次重置。计数来自引擎实际时间线，不由屏幕刷新或已练分钟推算。全屏与嵌入卡片读取同一份计数。

## 音色、试听与调音

七音色按现有 allCases 顺序固定编号 1–7，± 到两端停止，编号与卡片单一选择。非运行时选择并试听两小节，不启动实际练习计时、倒计时、训练历史或正式小节计数。耳机按钮可重复试听，先结束旧试听，不能叠加。

运行时切换从下一次发声使用新音色，不重启 BPM、节拍相位或小节；耳机按钮不再叠加第二条试听。音量/静音亦不重启引擎。已排入音频队列的缓冲区要纳入验证，不能仅证明属性发生了变化。

调音先输出可播放的同节奏 A/B：默认木质、干净电子、强拍对照，保留相同音量基准和快速细分测试。用户试听决定后再替换正式素材；该评审是 Q7 已确认的内容选择步骤，不是重新征求功能授权。七种预设名、rawValue、许可记录及 14 份普通/强拍资产保持完整。

复用现有样本时间调度与预加载，不在音频回调读文件。保持现有 70ms 素材契约，避免当前强饱和与过度降速造成的音质；若候选需要改变契约，必须同步测试和明确变更理由，不能凭听感跳过快速细分验证。

## 笔记、媒体与失败恢复

文本最后一次修改 600ms 后保存；新的输入取消过期任务，成功状态才显示“已保存”，提交中显示“保存中”，失败保留草稿并可重试。退后台、返回、完成先 flush 当前版本；历史详情仍按现有入口权限，自动保存文本不能绕过累计时长和完成锁定。

图片仍最多三张，JPEG 压缩和文件所有权沿用现有服务。导入使用系统 fileImporter，接受图片、可读取的音频和视频；拒绝不支持或无法解码的文件并说明原因。导入文件先复制进应用私有目录、读元数据，再保存关系；失败回滚本次新增文件，保留原内容。一次导入期间显示进度并防重复提交，不额外人为限制原已支持的音视频数量。

录音波形读取真实 AVAudioRecorder 电平，显示平滑后的短窗口；暂停时冻结，停止后清除活动波形。电平采集不依赖 SwiftUI 动画计时模拟，不能把固定柱形图当实时输入。

权限拒绝/受限、无摄像头、文件选择取消、损坏文件、磁盘写入失败、数据库保存失败都可恢复。失败不得显示已保存、标记完成或提前 detach pending；错误不包含用户笔记与媒体内容。
