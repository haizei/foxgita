# 原谱自动读取与直接跟练验收

2026-11-07。依据用户最新纠正“不是让人标记，而是直接读取谱子后跟练”。此前手工标记版的流程验收记录仅作为历史，不代表当前入口。

## 实现与结果

- 上传图片/PDF → 本机自动读取谱行、小节边界、拍号 → 自动存入我的曲谱 → 直接待机；已删除手工画框/行拍数输入和确认发布页面。
- 进入后可以立即播放，或点击训练范围右侧“3 秒准备”；准备取消不计练习时长，关闭后材料可重新打开。
- 用户本次提供的完整 iPhone 截图作为真实输入，读取出 **4 行、16 小节、64 拍**（拍号明确显示沿用 4/4）。没有手工标注，没有网络识谱调用。
- 清晰谱页上的上下排 **6/16** 能覆盖继承的 4/4 设置；缺小节线、空白页、混入失败页均拒绝发布，保留原件重试。读取关闭即时使本次结果失效。
- 游标仍是整行匀速；拍号未读到时显示沿用值，BPM 显示为练习速度。此验收不证明逐音识别、弱起、不完整小节、变拍或反复跳转的准确还原。

本轮基于现有完整工作区验证，保留其他任务尚未提交的跟谱基础、节拍器和 AI 改动。完整原生旧测试批次情况见 [历史验收](2026-11-07-original-score-line-following.md)，本轮不将旧批次失败宣称为已全量通过。

小字号拍号加测发现整体 OCR 曾漏掉真实页眉的 4/4；最终使用实际调号字符框、分数横线与上下数字分别读取。清晰原谱用例设置 `GITA_ORIGINAL_SCORE_METER_REQUIRED=1`，要求读取来源不能是“沿用”；分母16、无拍号反例与清晰原图均通过。完整App截图的小字号拍号在严格校验中仍未读出，按规格明确显示沿用值；截图的布局读取与清晰原谱的拍号读取分别验收，不将二者混为同一识别准确性结论。
