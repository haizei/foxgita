# ADR-0020：原谱标记修订保留版本，删除不改写练习历史

状态：已采纳的产品数据边界（2026-11-06，开发访谈 Q9–Q11、Q14）。

原谱标记草稿与已确认材料分开；修改已保存材料后产生新版本，历史练习固定引用发生时的版本。若直接覆盖标记，旧练习的行位置、范围与当时谱面会被追溯性改变；因此接受保留版本和谱页的存储成本，保证历史可解释。只改行框位置保留进度；增删行、改变顺序、行拍数、拍号或起始拍位后，重置进度到全部行起点、关闭循环。

从我的曲谱删除材料只隐藏曲库入口，不删除已有练习历史及其引用谱页。不得因隐藏材料而回收仍被历史引用的版本或原件；本决定不承诺无限保留无引用的临时文件，也不把标记草稿归入自动识谱队列。
