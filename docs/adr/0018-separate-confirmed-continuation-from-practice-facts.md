# 将建议练习、未确认草稿和每日练习事实分别维护

2026-11-06，依据已确认的 AI 重点方向与开发追问 Q7–Q12：生成结果保留为来源记录的未确认草稿，只有用户明确保存才成为首页「建议练习」；每份档案最多一条未完成重点，新内容不得静默替换旧安排。它关联来源练习和可用材料，以独立行动身份定位当天练习，不根据标题或未经采纳的媒体复盘结果匹配，避免把建议生成、打开页面或重试保存误记为实际练习。

可选的项目当前重点更新是一次性独立操作；续练重点保存成功、项目更新失败时保留已确认重点，并单独报告与重试项目更新。项目重点发生冲突时展示最新值，由用户重新决定是否覆盖，不回滚已保存的练习事实。该选择优先保住用户采纳的行动，代价是界面必须分别表达两个操作结果。

首页「进行中」包含中途暂停但未明确完成的练习；沿用离开单项面板即暂停的既有行为，首页呈现「已暂停／继续」，进入原面板后明确恢复才继续计时。本次不把单项运行状态提升为跨页面持续计时。明确完成事件与实际时长分别判断，不能用时长大于零推断完成。
