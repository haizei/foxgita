# ADR-0015：内置云端识谱服务，草稿经用户校正确认后用于跟练

状态：已采纳的产品边界（2026-11-01，跟谱开发访谈 Q4–Q6、Q9–Q10）；供应商和具体部署尚未选定。

印刷六线谱与五线谱的 PDF/清晰照片通过产品内置的云端识谱服务处理，上传前明确告知用户；普通用户不必配置自己的 API Key。选择这一边界而非沿用自配 AI 服务，是为了提供一致的识谱能力和失败处理。识别结果保存为可对照原件校正的草稿，用户确认后才用于跟练，不把自动识别完成等同于正确曲谱已发布。

校正范围为改正识别结果，不扩展为从空白制谱。本决定不代表任一第三方 OMR 已支持吉他 TAB，也不授权听弹音频上传、静默发送文件、采购服务或预设任何识别准确率；这些边界须分别验证和确认。
