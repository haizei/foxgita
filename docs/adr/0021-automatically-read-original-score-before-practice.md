# ADR-0021：原谱上传后自动读取并直接跟练

状态：采纳，2026-11-07，依据用户纠正：“不是让人标记，而是直接读取谱子后跟练”。

替代 ADR-0019 的手工标行流程，以及原规格 Q2/Q5/Q6/Q9/Q12/Q14/Q15 中要求用户框选、填写拍数、手动排序和显式发布的交互。保留原谱整页、整行匀速、我的曲谱、版本历史、当天计时、范围、循环与可选三秒准备。

上传后在设备上读取谱行和实际小节边界；拍号支持文字与上下排版读取，没有读到则明确显示沿用值。BPM 为用户可调的练习速度，不冒充谱面识别结果。全部页面读取成功后自动保存材料并进入待机。无需用户逐行框选或逐个填写拍数，也不以音符校正作为开始前提。

读取对象是谱面布局及小节结构，不是逐音 OMR。每行总拍数按已读小节数乘拍号分子；游标整行匀速，因此首版不承诺弱起、变拍、自由速度、反复跳转和不完整小节的精确时间，也不生成音符示范音或评分。

不能确认小节边界时显式失败并保留原文件供重试，不把切图组件的整页/整行回退结果当作“一小节”，不静默漏掉失败页，不退回手工标记必经流程。重新读取产生新版本，历史不变；既有手动版本仍可播放，但不再提供手动标记入口。
