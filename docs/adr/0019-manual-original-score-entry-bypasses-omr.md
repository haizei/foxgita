# ADR-0019：原谱跟弹作为无需识谱校正的独立练法入口

状态：手工标行部分已被 [ADR-0021](0021-automatically-read-original-score-before-practice.md) 替代；以下保留历史决策。原状态：已采纳的产品边界（2026-11-06，用户选择原谱整页跟弹与入口方案 3，并要求更新 Figma 流程）。Q1–Q15 的行时间、保存和运行规则已补齐至开发规格。

在“跟谱练习”下保留“曲谱跟练”，另设“原谱跟弹”：用户导入谱页并自行标定谱行后进入跟弹，不要求先完成自动识谱和音符校正。选择这一入口而非继续依赖识谱草稿的部分确认发布，是为了让用户直接使用已有谱子开始练习。谱行标记不代表音符或小节结构已经确认，因此不能借此生成可信的音符示范或演奏评分。

ADR-0017 仍约束交互曲谱中的原谱小节；本决定新增一条手动标行的练法，不把两者的数据语义混同，也不取消既有曲谱跟练、识谱或评分范围。本 ADR 不规定持久化技术，也不承诺两条路径之间的自动转换；不能由界面中的分段选择推断两者是同一文档的一次显示切换。
