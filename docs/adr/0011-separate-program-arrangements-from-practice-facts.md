# ADR-0011：统一练习偏好，分开安排与实际练习事实

状态：已采纳（2026-10-26，Issue #58）

## 决策

首次补充信息与调整偏好共用 Guitar DNA 八题。问卷草稿、已提交偏好、方案草稿、已保存方案分别生效。提交刷新候选和新草稿；明确保存才替换首页方案，不改写今日清单或训练快照。

顶部播放执行整套方案；首页底部按钮按 2026-10-27 的设计调整为「创建练习」，与「＋」共用创建弹窗，不再启动今日清单训练。今日清单中的练习逐项点击开始或继续；已有方案的暂停状态不因打开创建弹窗而改变。重复候选按分类、标题及训练主题判断，不按槽位或标题单独判断。

方案安排和训练关联保存于每个档案的原子 JSON 文档。实际时长仍只通过 PracticeStore 写入 PracticeItem；不增加可累加的 Session 时长。汇总通过实际项引用及起止秒数计算，防止同一每日项后续复练改变旧汇总。清单完成标记和分段推进在同一次安排文档提交中保存。

暂停排除间隔；次日继续创建次日事实并保留前日事实。连续跨午夜的运行区间按本地日期拆分，稳定来源身份支持失败重试。跳过和提前结束只保留已发生时长，不补齐计划时间。

## 后果

安排文件写入成功才更新可见状态；读取失败保留原文件并阻止覆盖。实际事实与安排提交属于不同存储，通过稳定身份及绝对累计时长支持重复保存。统计继续遍历 PracticeItem，不额外累加汇总。

问卷结果表达偏好方向，不表示能力评分。推荐采用透明的本地规则；算法权重、训练目录扩充和外部模型不属于本次变更。
