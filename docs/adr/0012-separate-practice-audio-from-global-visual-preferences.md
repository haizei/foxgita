# 分离每条练习的节拍配置与全局视觉偏好

新版练习 UI 将音效、音色和视觉设置放在同一个 Sound Sheet 中，但它们不因此共享数据归属。速度、拍号、细分、重音及声音参数随每条 PracticeItem 保存；节拍模块、钟摆模式、三级高亮过滤及小节计数显示选择作为应用内各练习共用的视觉偏好保存。倒计时继续遵循 ADR-0006，仅属于当前详情访问。本轮不引入项目默认值或步骤覆盖继承。

节拍模块与钟摆模式可同时开启，视觉高亮过滤不能修改真实发声的 Accent Pattern。该决定替代旧的“四种互斥 Beat Track Mode、仅当前练习保留”的显示模型，保留现有音频时间线及练习事实边界。

把全部设置随练习保存会使用户在每条练习中重复设置显示偏好；引入“步骤 → 项目 → 默认”的继承链则要求新增当前不存在的步骤身份与项目配置。两者均不适合作为本次界面改造的隐含代价。后续若需要继承，应另行定义所有权和数据迁移，不能将旧产品资料中的继承描述当作已存在的数据模型。
