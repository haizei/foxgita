# ADR-0017：小节结构确认后即可原谱跟练，音乐内容确认后才出示范音与判定

状态：已采纳（2026-11-05，原谱跟练开发访谈 Q1–Q6）；部分替代 ADR-0015 中“用户确认后才用于跟练”的边界。

导入曲谱经用户确认曲名、小节划分、拍号和速度后即可加入我的曲谱，并在原谱视图中跟练；未完整校正音乐内容的小节作为原谱小节发布，不产生示范音和听弹判定。选择这一边界而非继续要求整首逐音校正，是因为本机识谱在中文弹唱谱上可直接发声的内容比例很低，整首校正的负担使用户无法当天开始练习。ADR-0015 中“自动识别完成不等于正确曲谱已发布”的原则不变：原谱小节从不把未确认的识别结果当作音乐内容播放或评分。

原谱小节以显式状态标记，不用“没有音符”表示；缺少该状态的已有小节按已确认读取，避免改变以往经用户确认的曲谱含义。补校只产生新版本，不覆盖已确认版本；小节结构相同时，难点片段、续练进度和练习关联随修订指向新版本，练习结果和实际时长始终属于发生时的版本，沿用 ADR-0011 与 ADR-0013。
