# ADR-0016：听弹本地处理，示范音来自曲谱，仅谱页上传识谱

状态：已采纳（2026-11-01，跟谱开发访谈 Q12–Q13）。

完整和弦、扫弦节奏与综合评分的实时分析在设备上执行，不把弹奏声音流式上传或送往云端复盘。云端仅接收用户已被告知并主动导入的谱页。采用这一边界而非把全部分析统一交给云端，保留实时反馈的本地运行方式，并避免将谱页上传许可扩大成声音上传许可；用户主动录音仍属于独立的本地练习媒体保存。

导入曲谱通过确认后的音乐内容生成示范音及节拍器；内置原创练习谱可带原创伴奏。不引入个人伴奏导入/自动对齐，也不按曲名自动取得原曲录音。技术实现必须分别满足本地分析和云端识谱的验收，不能以远端音频请求、调音器单频读数或假命中替代已承诺能力。
