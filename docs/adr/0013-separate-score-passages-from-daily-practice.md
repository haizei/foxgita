# ADR-0013：曲谱难点、续练位置与每日练习事实分开

状态：已采纳的产品边界（2026-11-01，依据用户确认的 Figma 难点流程）；本 ADR 不决定本轮听弹识别范围、曲谱导入格式或存储实现。

难点片段属于可反复使用的曲谱材料，不属于某一天的临时练习，也不等同于上次播放位置。用户可以保存多个难点，之后再次专项练习；续练进度分别保留。采用这一边界而不把难点仅塞进当日练习笔记，是为了跨天仍能找到并复用同一片段，也避免“从头重练”或继续播放意外覆盖用户标记。

实际时长继续归属发生当天的 PracticeItem，难点和曲谱不产生第二份可累加时长。跨天继续不向历史练习追加时长，沿用 ADR-0011。曲谱版本变化、删除、迁移和归档策略仍须在跟谱开发访谈中确认，不能据此 ADR 推断实现细节。
