# Separate AI-derived review data from user-approved mutations

Gita distinguishes Practice Drafts, Review Results, and Candidate Memory. Practice Drafts require editable preview and Host Approval before creating practice data; approval binds the final draft hash and becomes invalid after edits. Review Results may be attached automatically to their source Recording because they are derived analysis, while Candidate Memory requires separate in-context approval because it changes the user's durable profile. Chat text never constitutes approval, and ignored candidates are suppressed for the same evidence and meaning without blocking future candidates based on new evidence.
